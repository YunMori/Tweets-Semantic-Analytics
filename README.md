🐥 트위터 감성 분석 프로젝트 (Twitter Sentiment Analysis) 


우송대학교 기업 실습 프로젝트 

📝 프로젝트 개요
본 프로젝트는 소셜 미디어(Twitter) 상의 방대한 데이터를 감성 분석하여, 기업이 자사 제품 및 서비스에 대한 고객의 경험과 반응을 실시간으로 파악할 수 있는 인사이트를 제공하는 것을 목표로 합니다. 기존의 설문조사나 인터뷰 방식의 한계를 넘어, 실시간 데이터를 활용한 고객 경험 추적 솔루션을 탐색했습니다.



🎯 주요 목표
**EDA(탐색적 데이터 분석)**와 **BERT(Transformer Encoder)**를 통한 정밀한 감성 분석 모델 구현.

다양한 머신러닝 및 딥러닝 모델의 성능 비교를 통한 최적의 분류 모델 탐색.

📊 데이터셋 정보

출처: Kaggle 'Sentiment 140 dataset with 1.6 million tweets'.


구성: 트위터 API를 통해 추출된 160만 개의 트윗 데이터.


필드: target(감성 레이블), ids, date, flag, user, text 등 6개 필드.


레이블: 0 = Negative, 2 = Neutral, 4 = Positive.

🛠 데이터 전처리 과정 

비형식적인 구어체가 많은 트위터 데이터의 특성을 고려하여 세밀한 전처리를 수행했습니다.

URL, HTML 태그, 멘션(@), 해시태그(#), 구두점, 이메일, 숫자 등 제거.

모든 문자의 소문자화 및 반복 문자 처리.

이모지 제거 및 불용어(Stopwords) 처리.



토큰화(Tokenization): 감성 분석에 중요한 축약어(e.g., "doesn't") 처리를 위해 TweetTokenizer 등을 활용.



표제어 추출(Lemmatization).

⚠️ 한계점 및 개선 방향

중립 감성 처리: 데이터셋 자체에 중립 레이블이 부족하여 분류 성능에 이론적 상한선이 존재함을 확인했습니다.



컴퓨팅 자원: BERT와 같은 거대 모델 운영 시 실시간 서비스화를 위한 컴퓨팅 파워 확보 및 최적화가 필요합니다.
