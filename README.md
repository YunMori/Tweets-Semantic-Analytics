# 🐥 트위터 감성 분석 프로젝트 (Twitter Sentiment Analysis)

**우송대학교(Woosong University) 기업실습 프로젝트**

## 1. 프로젝트 개요
본 프로젝트는 소셜 미디어 데이터를 통해 자사 제품 및 서비스에 대한 고객의 경험을 실시간으로 추적하고 인사이트를 발굴하는 것을 목표로 합니다. 기업이 기존에 활용하던 설문조사나 인터뷰 방식의 한계를 보완하기 위해 실시간 데이터 분석 솔루션을 연구하였습니다.

* **목표**: EDA 및 BERT 모델을 활용하여 최적의 감성 분석 성능 도출
* **주요 과제**: 대규모 텍스트 데이터 전처리 및 딥러닝 모델 성능 비교

## 2. 데이터셋 정보
* **출처**: Kaggle 'Sentiment 140 dataset with 1.6 million tweets'
* **규모**: 트위터 API로 추출한 160만 개의 트윗 데이터
* **필드 구성**: `target`, `ids`, `date`, `flag`, `user`, `text`
* **레이블링**: 0 (Negative), 2 (Neutral), 4 (Positive)

## 3. 데이터 전처리 (Preprocessing)
비형식적인 구어체가 많은 트위터 텍스트의 특성을 반영하여 정교한 전처리를 수행했습니다.
* **데이터 클리닝**: URL, HTML 태그, 멘션, 이메일, 숫자 등 제거
* **텍스트 정규화**: 소문자 변환 및 반복되는 철자(예: Coooooool) 처리
* **토큰화 전략**: 감성 분석에서 의미가 큰 "NOT" 등을 보존하기 위해 `TweetTokenizer` 활용
* **축약어 복원**: `isn't` → `is not`, `dont` → `do not` 등 텍스트 표준화
* **기타**: 불용어 제거 및 표제어 추출(Lemmatization)

## 4. 모델별 성능 비교
다양한 알고리즘을 테스트하여 최적의 분류 모델을 탐색하였습니다.

| 모델명 | 훈련 정확도 | 검증 정확도 | 테스트 정확도 | 비고 |
| :--- | :---: | :---: | :---: | :--- |
| **나이브 베이즈(NB)** | 0.793 | 0.765 | **0.768** | 계산이 빠르고 노이즈에 강함 |
| **서포트 벡터 머신(SVM)** | 0.730 | 0.729 | **0.732** | 과적합 회피에 유리함 |
| **VADER** | 0.636 | 0.636 | **0.638** | 비지도 학습 기반, 가장 낮은 정확도 |
| **BERT (최종)** | - | 0.846 | **0.848** | **최고 성능 모델 (BERTweet)** |

## 5. 결론 및 고찰
* **성능 개선**: 단순 신경망(LSTM)과 CNN의 한계를 BERT 적용으로 극복하여 정확도를 **0.84**까지 향상시켰습니다.
* **데이터 한계**: 중립 감정 레이블의 부재로 인해 실제 중립 데이터가 긍정/부정으로 분류되어 성능 상한선(이론적 최대 약 80%)이 존재함을 확인했습니다.
* **운영 과제**: BERT의 거대한 모델 크기로 인한 컴퓨팅 파워 부족 및 실시간 서비스 적용 시 속도 저하 문제가 확인되었습니다.
* **발전 방향**: 체계적인 버전 관리를 위해 Git 활용의 필요성을 체감했습니다.
